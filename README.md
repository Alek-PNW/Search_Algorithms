# Search Algorithms

Overview of search algorithms, BFS, DFS, UCS, A\* Search, by using 4 different methods to find the answer of what path to take traversing a graph.

## Description

4 algorithms showcasing differences in uninformed and informed searching using map information from the western United States. Depth-First Search, Breadth-First Search, Uniform-Cost Search, and A\* search. Algorithms generate 5 pairs of starting and ending nodes before performing searches on each.

## Getting Started

### Dependencies

- **Python >= 3.11**

### Installing

- Download and unzip folder

### Executing program

- Open directory of installation

- Windows  
  Open command terminal and run
  ```
    python search_algorithms.py
  ```
- Linux / Mac  
  Open command terminal and run
  ```
    python3 search_algorithms.py
  ```
